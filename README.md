# اختبارات القرآن الكريم — تطبيق تفاعلي لجميع سور القرآن

تطبيق عربي تفاعلي لاختبار حفظ القرآن الكريم وفهمه: أسئلة موثقة لجميع سور القرآن الكريم الـ114، مقسمة إلى اختبارات صغيرة منظمة تناسب طول كل سورة، بواجهة عربية أندلسية الطابع تعمل على الهاتف والكمبيوتر، وقابلة للنشر مباشرة على GitHub Pages.

## المميزات

- **جميع السور الـ114** مرتبة حسب المصحف، مع رقم كل سورة واسمها وعدد آياتها وتصنيفها (طويلة/متوسطة/قصيرة) ومكيّتها أو مدنيتها وأجزائها.
- **254 اختباراً** مقسماً بذكاء: السور الطويلة تنقسم إلى أجزاء آيات محددة، والمتوسطة اختبار أو اختبارين، والقصيرة تُجمع في مجموعات بترتيب المصحف، إضافة إلى مراجعات شاملة.
- **أكثر من 5600 سؤال** بأنواع متنوعة: إكمال الآية، اختيار الكلمة الناقصة، الآية التالية والسابقة، المواضع المتشابهة، معاني المفردات في ضوء التفسير، ومعلومات السور.
- **محرك اختبار كامل**: خلط الاختيارات مع كل محاولة، ثلاث مساعدات لحذف إجابة خاطئة، شريط تقدم نجومي، نتيجة من 100، مراجعة كل سؤال بعد الانتهاء، إعادة الاختبار بترتيب جديد.
- **حفظ محلي كامل (localStorage)**: نتائج كل اختبار وأفضل درجة وعدد المحاولات، وإمكانية متابعة اختبار متوقف لاحقاً — دون أن تُمحى النتائج السابقة عند إضافة اختبارات جديدة.
- **تحميل أسئلة الاختبار مع الإجابات في PDF**.
- **بحث وفلترة**: بحث باسم السورة أو رقمها، وفلترة حسب التصنيف أو الجزء.
- **دعم لوحة المفاتيح**: أرقام 1-4 أو حروف أ ب ج د للاختيار، و Enter للتأكيد والانتقال.

## الدقة القرآنية ومصدر النص

هذا هو الأساس الذي بُني عليه المحتوى كله:

- النص القرآني معتمد من **مشروع تنزيل (Tanzil)** — نسخة Simple (Plain) الرسمية الموثقة من [tanzil.net](https://tanzil.net)، وقد وحّدتها أداة التجهيز مع أسلوب الإملاء المعتمد في المشروع (توحيد ترتيب علامات التشكيل NFC، وإزالة الألف الخنجرية في غير «الرَّحْمَٰن») دون أي تغيير في الحروف أو الحركات.
- كل آية وكل خيار في الأسئلة المولدة **مستخرج حرفياً من هذا النص** — لا يوجد نص قرآني مكتوب يدوياً في الأسئلة الجديدة، ولا تتمات مُخترعة، فالمشتتات نفسها مقاطع قرآنية حقيقية (تتمات آيات متشابهة البدايات، أو كلمات قرآنية بنفس النمط الإعرابي).
- **أداة تحقق آلية** (`tools/verify.py`) تفحص كل سؤال بعد التوليد: مطابقة الإجابة الصحيحة حرفياً بالنص المصدر، وحدود أرقام الآيات، وعدم تكرار الأسئلة بين الاختبارات، وسلامة الحقول. آخر تشغيل: **صفر أخطاء وصفر تكرارات** — التقرير في `tools/verification-report.md`.
- أسئلة سورتي يس والرحمن الأصلية للمؤلف نُقلت كما هي دون تغيير، وجرى التحقق منها آلياً أيضاً؛ إصلاح تشكيلي واحد وُجد ومُوثق في التقرير (خيار «تَخْسَرُوا» صُحح إلى «تُخْسِرُوا» وفق النص).
- أسئلة المكي/المدني تولّد فقط للسور التي لم يختلف فيها العلماء؛ والسور المختلف فيها (الرعد، الحج، الرحمن، الإنسان، الزلزلة، النصر) استُثنيت من التوليد الآلي التزاماً بشرط «عند ثبوت المعلومة»، مع إبقاء سؤال المؤلف الأصلي لسورة الرحمن بصيغته (مكية عند جمهور العلماء).
- معاني المفردات مقصورة على كلمات ثابتة المعنى عند جمهور المفسرين (ابن كثير، الطبري، السعدي، مجمع البيان)، ويتحقق التطبيق آلياً من وجود الكلمة في موضعها قبل توليد السؤال.

### صيغة ملف الأسئلة

كل اختبار في ملف مستقل يسجل نفسه في مساحة الأسماء `window.QUIZ_DATA` فلا يحدث أي تعارض بين الملفات:

```js
window.QUIZ_DATA = window.QUIZ_DATA || {};
window.QUIZ_DATA["q-036-1"] = {
  "id": "q-036-1",
  "title": "سورة يس — الجزء الأول (الآيات 1-28)",
  "surahs": [36],
  "ayahRange": [1, 28],
  "source": "Tanzil (Simple Plain)",
  "questions": [
    {
      "q": "أكمل الآية الكريمة (2): ﴿ذَلِكَ الْكِتَابُ ...............﴾",
      "options": ["لَا رَيْبَ فِيهِ هُدًى لِلْمُتَّقِينَ", "...", "...", "..."],
      "correct": 0,
      "surahNumber": 36,
      "ayahNumber": 2,
      "type": "complete_ayah"
    }
  ]
};
```

أنواع الأسئلة المعتمدة: `complete_ayah` (أكمل الآية)، `word_blank` (الكلمة الناقصة)، `next_ayah` و`prev_ayah` (الآية التالية/السابقة)، `similar_ayah` (المواضع المتشابهة)، `vocab` (معاني المفردات)، `surah_ayahs_count` و`surah_order` و`surah_revelation` (معلومات السورة)، `general` (أسئلة عامة). الحقل `correct` يبدأ من الصفر، والمحرك يخلط مواضع الاختيارات تلقائياً في كل عرض.

## كيف تضيف سؤالاً أو اختباراً جديداً

### إضافة أسئلة يدوية إلى سورة قائمة

1. أنشئ ملفاً جديداً في مجلد السورة، مثل `js/data/surah-002/custom-01.js`، بنفس الصيغة أعلاه مع معرّف فريد غير مستخدم (مثل `q-002-c1`).
2. سجّل الاختبار في `js/quiz-registry.js` بإضافة سطر يصفه (النص، السور، النطاق، عدد الأسئلة، مسار الملف، المجموعة) — سيظهر تلقائياً في الصفحة الرئيسية وفي محرك الاختبار.
3. إن أردت ظهوره ضمن قائمة اختبارات السورة في البطاقة، أضف كائنه المختصر إلى `quizzes` الخاصة بالسورة في `js/surah-registry.js`.

وإلا فالأبسط: أضف الأسئلة داخل قائمة `questions` في ملف اختبار قائم، ثم حدّث حقل `count` في السجلين.

### إعادة توليد المحتوى أو التحقق منه

```bash
# تجهيز النص الموثق (يحتاج ملفات tools/cache الأصلية أو تنزيلها من Tanzil)
python3 tools/prepare.py

# تحويل أسئلة المؤلف الأصلية ثم توليد كل الأسئلة والسجلات
node tools/migrate-legacy.js
python3 tools/generate.py

# التحقق الآلي الشامل من كل الأسئلة
python3 tools/verify.py
```

## التشغيل والنشر على GitHub Pages

التطبيق ملفات ثابتة بالكامل (HTML/CSS/JS) بلا أي واجهة خلفية أو مفاتيح سرية:

- **محلياً**: `python3 -m http.server 8000` ثم افتح `http://localhost:8000`.
- **GitHub Pages**: من إعدادات المستودع اختر الفرع `main` والمجلد `/ (root)` — سيعمل التطبيق مباشرة على رابط الصفحة. جميع الروابط نسبية فتعمل تحت أي مسار فرعي.
- الأداء: لا تُحمَّل أسئلة أي اختبار إلا عند فتحه (ملف واحد صغير لكل اختبار)، وسجلّا السور والاختبارات بيانات وصفية خفيفة تُحمَّل مرة واحدة.
